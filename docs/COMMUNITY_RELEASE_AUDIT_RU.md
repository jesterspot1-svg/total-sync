# Аудит TotalSync 0.2.0

Дата: 7 ноября 2026. Выпуск подготовлен по просьбе пользователя для подачи в Community Directory. Одобрение каталога не подменяется публикацией GitHub.

## Проверка и очистка

- Подключён официальный `eslint-plugin-obsidianmd`; проверяются исходники, manifest, package и LICENSE. Тесты и сборочные скрипты проверяются отдельно от ограничений мобильного runtime.
- Удалены лишние утверждения типов, повторная проверка подписи и повторный GET уже подтверждённого профиля. Проверки SHA-256 полученных файлов сохранены.
- Использованы API создания элементов Obsidian и отдельный CSS-класс вместо встроенной ширины. Для опасных кнопок выбран актуальный API с совместимостью Obsidian 1.11.5–1.12. Учтён активный документ приложения.
- Runtime не включает Node.js, Electron и внешние библиотеки. Закрытые ключи, локальные журналы, резервные копии и данные пользователя не входят в релиз.
- Сохранены старые профили Calendar/Excalidraw, прежний облачный формат и имя корня: они нужны для совместимости существующих установок, а не являются неиспользуемым кодом.
- Обновлены README на русском и английском, история выпусков, пользовательская инструкция, сведения о сети, аккаунте, оплате, хранении данных и известных ограничениях.

## Оптимизация плагинов

Применение одного плагина раньше трижды перечитывало пакеты остальных плагинов. Теперь независимая проверка до выгрузки, после выгрузки и после применения ограничена затронутым плагином. Проверки плана, откат и восстановление сохранены.

В регрессионной фикстуре число чтений посторонних пакетов снизилось с **12 до 0**. Манифест с форматированием читается один раз за проход, а не два; исходный размер файла больше не смешивается с размером канонического JSON. Это измерение количества операций на стенде, не обещание конкретного ускорения WebDAV Mail.

## Блокировки и повторные попытки

- Обычные маленькие файлы готовятся параллельно, большие — последовательно, **до** получения общей блокировки. Сразу после её получения повторно проверяется актуальность облачного индекса.
- Автоматический повтор не теряется, если таймер сработал во время другой операции TotalSync. Возвращение сети ускоряет ожидание; успешный новый проход отменяет старый таймер. Выключение синхронизации отменяет ожидающие повторы.
- Временные ошибки, включая неопределённую запись или снятие блокировки, вызывают безопасный повтор полного прохода. Это повтор чтения и проверки журнала, а не слепое повторение опасного DELETE. Плашка показывает задержку, журнал — `retry-scheduled seconds=…`.
- Ошибка профиля плагинов не скрывает необходимость повторить синхронизацию заметок.
- Существующий журнал восстанавливает свою публикацию после HTTP 504 и перезапуска; проверяются исходный хеш, родитель и номер ревизии. При неожиданном индексе запись прекращается.

**Граница автоматизации:** старую пустую блокировку неизвестного владельца и неопределённый DELETE общего пути нельзя всегда безопасно исправить автоматически. Такие случаи сохраняют защиту и могут требовать диагностики. Подготовка конфликтов всё ещё может удерживать блокировку. Обещания полного отсутствия блокировок нет.

## Автоматические проверки

Локально прошли TypeScript, ESLint, **114 тестов**, сборка, запуск собранного плагина с имитацией Obsidian API и проверка безопасности состава релиза. Аудит зависимостей: **0 известных уязвимостей** на момент проверки.

Новые сценарии подтверждают загрузку маленького и большого файла вне блокировки, отсутствие блокировки после обрыва во время загрузки, пересчёт плана при записи другого устройства и отсутствие потери правок. Smoke-проверка запускает отложенный повтор после освобождения занятой операции, проверяет сообщение, ускорение по событию сети и отмену при выключении. Существующие тесты подтверждают восстановление своей публикации, защиту чужой/неизвестной блокировки, невозможность повторного неопределённого DELETE, потерянные ответы сервера и продолжение порционной отправки.

ESLint оставляет одну неблокирующую рекомендацию: перевести динамическую страницу настроек на декларативные определения для поиска настроек новых версий Obsidian. Текущая страница сохраняет совместимость с минимальной версией. Рекомендация не скрыта отключением правила.

GitHub Actions повторяет проверки на Windows и Linux и отдельно собирает файлы тега. Результаты CI и состав опубликованного релиза доступны в GitHub; локальный отчёт сам по себе не является доказательством завершённого CI.

## Что подтверждено на устройствах

Пользователь подтвердил синхронизацию BTV_Base на двух ноутбуках и iPhone, перенос настроек, работу мобильных кнопок и разбора конфликтов. Настройка вертикальных линий Outliner 4.10.2 проверена в обе стороны; на новом ноутбуке сверены файл и работающий экземпляр плагина.

Ручное отключение сети и стационарный ПК отложены пользователем. Все настройки всех сторонних плагинов вручную не проверены. Android, macOS и Linux не прошли ту же ручную приёмку, что Windows/iPhone. Файлы iOS буферизуются в памяти; отсутствие лимита TotalSync не отменяет ограничений устройства.
