# Плагины между Windows-устройствами

## Установка недостающих из каталога

1. В `TotalSync-Beta` на старом ноутбуке запустите синхронизацию. На новом ноутбуке запустите её снова, затем нажмите **Ctrl+P → TotalSync: Сравнить установленные плагины**. Выберите список старого ноутбука. TotalSync показывает ID, версию, отметку включения и состояние на новом ноутбуке.
2. Для одного плагина нажмите **Открыть в каталоге** в его строке. В Obsidian откройте **Настройки → Сторонние плагины → Обзор**, проверьте имя и автора, нажмите **Установить** и при необходимости **Включить**. Например, ID Excalidraw — `obsidian-excalidraw-plugin`, автор — zsviczian. [Страница Excalidraw](https://community.obsidian.md/plugins/obsidian-excalidraw-plugin) · [Справка Obsidian](https://obsidian.md/help/community-plugins)
3. Для пакетной установки на новом ноутбуке настройте штатный Obsidian CLI через **Настройки → Общие → Интерфейс командной строки**. Требуется установщик Obsidian 1.12.7 или новее. На странице сравнения под списком старого ноутбука нажмите **Команды для установки**. Проверьте точное имя целевого vault и ID, скопируйте выбранные строки и запустите их в PowerShell. Строка с `enable` также включает установленный плагин. Если на компьютере два vault с одинаковым именем, используйте установку из каталога внутри нужного vault. [Настройка CLI и команда plugin:install](https://obsidian.md/help/cli#plugins)
4. Повторно откройте сравнение. Недостающие плагины, которые удалось установить, теперь отображаются с локальной версией. Obsidian выбирает версию из каталога. Частные и beta-плагины вне каталога требуют своей процедуры установки, например через BRAT. Плагины и их конфигурации из рабочего vault переносите только в рамках отдельно согласованной локальной миграции.

## Настройки Excalidraw 2.29.x

1. **Сначала обновите TotalSync до 0.1.3 на всех устройствах этого тестового vault, включая iPhone.** Старая версия TotalSync не распознаёт профиль Excalidraw в общем индексе. iPhone читает индекс и пропускает настройки Windows.
2. Установите Excalidraw 2.29.x на обоих Windows-компьютерах. На старом ноутбуке в Excalidraw измените проверяемый параметр, например ширину встроенного рисунка на `720` или формат вложения на SVG. В **Настройки → TotalSync** включите **Настройки Windows** и **Настройки Excalidraw**, нажмите **Синхронизировать сейчас**.
3. На новом ноутбуке включите **Настройки Windows** и **Настройки Excalidraw**, затем выберите **Принять настройки Excalidraw из облака → Применить профиль**. Эта команда нужна, если свежая установка уже записала параметры по умолчанию и они конфликтуют с профилем источника. Проверьте значение в настройках Excalidraw. Если панель показывает старое значение, заново откройте тестовый vault.
4. После первого принятия поменяйте тот же параметр на любом из Windows-компьютеров. Обычная синхронизация передаст новое значение второму. При независимых правках на обоих устройствах сохраняются версии для разбора. Если нужно вернуть старый профиль, сохраните его из истории TotalSync и сверяйте параметры локально.

Синхронизируются проверенные параметры отображения, ввода, сохранения, экспорта, размеров и некоторые пути внутри vault. Локально остаются ключи и профили AI/OCR, настройки скриптов, разрешения запуска, пути к шаблонам и скриптам, библиотеки внутри настроек, машинные пути, произвольный CSS и поля вне проверенного списка. Рисунки синхронизируются обычным каналом контента. Для остальных плагинов доступен инвентарь, а профиль настроек требует отдельной проверки. [Схема Excalidraw 2.29.1](https://github.com/zsviczian/obsidian-excalidraw-plugin/blob/2.29.1/src/core/settingsDefaults.ts)

Отключение **Настройки Excalidraw** останавливает перенос профиля на этом Windows-устройстве. Для отката TotalSync до 0.1.2 используйте другой тестовый UUID с отдельным vault. Опубликованный профиль остаётся в индексе прежнего UUID и требует 0.1.3.
