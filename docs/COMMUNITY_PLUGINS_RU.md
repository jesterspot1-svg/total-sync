# Плагины и настройки между ноутбуками — TotalSync 0.1.18

**Актуально для 0.2.0:** TotalSync уже доступен в [каталоге Obsidian](https://community.obsidian.md/plugins/total-sync). Обновление стабильной версии доступно в **Настройки → Сторонние плагины**; BRAT необязателен. У существующей пары BTV_Base профиль уже принят, перенос настройки Outliner проверен в обе стороны. Если стоит 0.2.0, ничего переустанавливать не нужно; повторять выбор источника и подключение профиля не требуется. Ниже сохранён протокол первой проверки 0.1.18 через BRAT. Для актуальной установки и обновления используйте [общую инструкцию](USER_GUIDE_RU.md).

Новый режим **Плагины и настройки** на Windows переносит файлы плагинов, точные версии, включение и переносимые настройки. Установка через PowerShell больше не нужна. Режим выключен по умолчанию и включается при выборе исходного профиля.

По выбору пользователя **новый ноутбук — исходный**, а **старый — получатель**. Рабочее хранилище на обоих — **BTV_Base**. Существующие хранилища не нужно создавать заново, очищать или повторно привязывать к облаку. Новый ноутбук задаёт первоначальные версии и настройки; после принятия профиля изменения синхронизируются в обе стороны.

Новая функция проверена автоматизированным стендом; проверка на вашей паре ноутбуков ещё предстоит. Для первой репетиции можно использовать имеющийся тестовый vault с искусственными данными. Перед применением к рабочему BTV_Base сохраните свежую локальную копию его папки, включая .obsidian, при закрытом Obsidian. После копирования откройте его снова. Это подготовка проверки новой beta, а не часть каждой синхронизации.

## 1. Сначала обновите TotalSync на обоих ноутбуках

1. Дождитесь завершения текущей синхронизации.
2. В открытом **BTV_Base** нажмите **Ctrl+P**, введите **BRAT** и выберите **BRAT: Plugins: Choose a single plugin version to update** (в старых BRAT — **Choose a single plugin to update**). В списке выберите **TotalSync** или **jesterspot1-svg/total-sync**. BRAT сам скачает файлы из GitHub и перезагрузит плагин; вручную скачивать файлы и раскладывать их по папкам не требуется.
3. Если TotalSync отсутствует в списке команды, проверьте **Настройки → BRAT**: закреплённые версии тоже могут быть скрыты из команды обновления (см. шаг 4). Если репозиторий там вообще не добавлен, нажмите **Add beta plugin**, введите **https://github.com/jesterspot1-svg/total-sync**, дождитесь списка версий, выберите **Latest version** и нажмите **Add Plugin**. Это добавляет существующий плагин под управление BRAT; предварительно удалять TotalSync не нужно. Если BRAT ещё не установлен на этом ноутбуке, установите его через **Настройки → Сторонние плагины → Обзор**, включите и затем выполните этот шаг.
4. Если обновление не предлагается, проверьте строку TotalSync в настройках BRAT: конкретная закреплённая версия (**frozen**) не обновляется автоматически. Нажмите значок редактирования рядом с репозиторием, выберите **Latest version** и нажмите **Change version**. Для проверки именно этого релиза можно выбрать **0.1.18**; тогда последующие версии потребуется выбирать отдельно. При задержке GitHub повторите проверку через несколько минут.
5. Откройте **Настройки → Сторонние плагины** и убедитесь, что версия TotalSync — **0.1.18** (или более новая, если она уже опубликована). Повторите обновление на втором ноутбуке. Только после обновления обоих переходите к выбору источника.
6. В обоих BTV_Base должна оставаться прежняя рабочая привязка TotalSync и включённая обычная синхронизация. Remotely Save оставьте выключенным. Для этой функции обновлять iPhone с 0.1.15 необязательно: Windows-профили на нём не применяются. Стационарный ПК пока не подключаем.

Обновление одного плагина выбрано намеренно: команда BRAT для всех beta-плагинов может обновить и другие плагины. [Справка BRAT по обновлению](https://tfthacker.com/brat-plugins) · [Работа с GitHub Releases и Latest version](https://tfthacker.com/brat-developers)

## 2. Опубликуйте настройки с нового ноутбука

1. На **новом ноутбуке** откройте **Настройки → TotalSync**.
2. В области данных нажмите **Плагины и настройки**. Также доступна одноимённая команда TotalSync через **Ctrl+P**.
3. Нажмите **Этот ноутбук — исходный**. Дождитесь окончания публикации. При первом проходе передаются файлы всех его плагинов, поэтому он дольше последующих.
4. Запишите короткий номер из строки **Это устройство** — он поможет выбрать нужный ноутбук на получателе.
5. Нажмите **Скопировать отпечаток**. Это открытый отпечаток ключа, не пароль. Перенесите скопированный текст на старый ноутбук доступным вам способом.

Эта операция включает новый режим. Старые отдельные переключатели Calendar и Excalidraw уступают ему место: один профиль не применяется двумя механизмами одновременно.

## 3. Подключите старый ноутбук к профилю

1. На **старом ноутбуке**, в существующем **BTV_Base**, откройте **Настройки → TotalSync → Плагины и настройки**.
2. Нажмите **Обновить источники**, если новый ноутбук ещё не появился.
3. Найдите строку **Ноутбук …** с номером из предыдущего раздела и нажмите **Получить этот профиль**. **Не выбирайте «Этот ноутбук — исходный» на получателе.** Начальные настройки получателя не публикуются поверх источника.
4. Дождитесь получения списка. Недостающие плагины из официального каталога устанавливаются в точной версии, если файлы этого релиза доступны и совпадают с исходным пакетом. Выключенный на источнике плагин остаётся выключенным.
5. Если указано **Подтвердите источник**, раскройте **Доверие к пакетам с ноутбука …** с номером нового ноутбука. Вставьте **отпечаток, скопированный на новом ноутбуке**, и нажмите **Сверить и доверять источнику**. Это необходимо для pdf-annotator, пакетов с дополнительными файлами и версий, не подтверждённых через каталог.
6. Доверие сохраняется для будущих подписанных пакетов этого ноутбука. Его можно отозвать в том же разделе. Отпечаток из неизвестного сообщения или файла облака не заменяет проверку на самом источнике.
7. Для работающих плагинов может появиться **Ожидает применения**. Завершите редактирование рисунков и диалогов этих плагинов. Нажмите **Применить ожидающие изменения**, просмотрите список и нажмите **Применить**. Затронутые плагины перезагрузятся; Obsidian останется открыт.
8. Нажмите **Синхронизировать плагины** ещё раз. В строках должны совпасть версии и появиться **Применено**. Если строка требует входа или локального пути, выполните эту настройку в самом плагине.

Уже установленные плагины на старом ноутбуке удалять не нужно. Их локальные пароли сохраняются. Плагины, присутствующие только на старом ноутбуке, после принятия исходного профиля публикуются как новые локальные установки при следующем проходе. Выбор исходного ноутбука не делает синхронизацию постоянно односторонней.

Шаги 2–3 описывают первое подключение профиля. Если ранее исходный профиль уже был создан на старом ноутбуке, простая смена ролей в инструкции не сбрасывает его состояние. Не выполняйте первичную настройку повторно: сначала уточните в переписке, какой профиль уже принят. Перепривязывать BTV_Base или удалять состояние ради смены источника не требуется.

## 4. Проверьте передачу в обе стороны

Для Outliner 4.10.2 сначала обновите TotalSync до **0.1.18 на обоих ноутбуках**. В 0.1.17 были указаны устаревшие имена его полей. [Пошаговая проверка вертикальных линий Outliner](OUTLINER_TEST_RU.md).

1. Сравните **Настройки → Сторонние плагины** на ноутбуках: наличие, версии и включение. Сам TotalSync исключён из переносимого списка. В исходном рабочем наборе было 16 других плагинов; если вы меняли набор, ожидаемое число будет другим.
2. На новом ноутбуке измените обычный параметр Excalidraw, например ширину встроенного рисунка на **720**. Закройте настройки Excalidraw, запустите синхронизацию TotalSync и дождитесь окончания.
3. На старом ноутбуке запустите синхронизацию. Если показано ожидающее применение, выполните его по шагу 3.7. Заново откройте настройки Excalidraw и проверьте **720**.
4. На старом ноутбуке измените тот же параметр на **760**. Синхронизируйте сначала старый, затем новый ноутбук. На новом должно появиться **760**. Верните желаемое значение тем же способом.
5. Повторите с обычным параметром другого плагина: например, **Words per dot** у Calendar или **Show result count** у Dataview. Если у плагина нет горячего перечитывания настроек, используйте **Применить ожидающие изменения**.
6. Повторите синхронизацию без правок. Старые значения не должны возвращаться, а конфликт не должен появляться сам по себе.
7. Для проверки отсутствующего плагина в тестовом vault установите один выбранный вами плагин через каталог Obsidian на источнике, затем синхронизируйте оба ноутбука. Проверьте появление, версию и включение на получателе. Удалять нужный плагин в рабочем vault ради проверки не требуется.
8. Если будущие обновления пакетов вне каталога будут исходить **со старого ноутбука**, один раз скопируйте его отпечаток на новый и подтвердите доверие в обратном направлении. Обычные настройки после подключения передаются в обе стороны без повторного подтверждения.

При автоматической синхронизации используются существующие параметры TotalSync. Файлы плагинов проверяются примерно каждые 15 секунд, затем действует заданная задержка после изменений. Обновление активного плагина всё равно может ждать безопасного применения. Для первой проверки удобнее ручной запуск.

## 5. Какие настройки остаются локальными

Перечни переносимых полей подготовлены для Calendar, Dataview, Auto Link Title, Book Search, Excalidraw, Outliner, Zotero Integration, BRAT, PDF Annotator, Periodic Notes, Telegram Sync, Templater, VK Inbox, Zotero Highlights Sync и ZotLit. Для Remotely Save переносятся пакет и включение, а подключение к облаку остаётся локальным.

- **Пароли, токены, ключи API и сессии** не передаются. На принимающем ноутбуке без действующей авторизации может потребоваться отдельно войти в Telegram/VK и другие сервисы. Существующая авторизация получателя сохраняется.
- **Абсолютные пути и разрешения запуска команд/скриптов** настраиваются отдельно. Например, путь к базе Zotero или программе может отличаться на ноутбуках.
- **Неизвестные поля** перечислены в **Локальные поля и дополнительные настройки**. Для нужного обычного предпочтения проверьте назначение, нажмите **Выбрать дополнительные поля** и разрешите его на обоих ноутбуках. Значения выбранных полей отправляются в Mail. Поля, распознанные как секреты или разрешения выполнения кода, выбрать нельзя.
- **Применено** означает совпадение пакета, включения и согласованных переносимых полей, а не всего data.json. Напоминание о локальном входе или пути может оставаться рядом с этим статусом.

Telegram/VK и другие импортеры не координируют фоновые задачи через TotalSync. Чтобы не запускать импорт одновременно на двух ноутбуках, выключите для такого плагина **Синхронизировать этот плагин на ноутбуке**, затем отключите сам плагин на этом ноутбуке. При таком исключении его версия, включение и настройки остаются локальными.

## 6. Ожидание, конфликт и восстановление

| Состояние | Действие |
| --- | --- |
| Ожидает применения | Завершите работу в затронутом плагине, просмотрите и примените ожидающие изменения. |
| Подтвердите источник | Скопируйте отпечаток с соответствующего ноутбука и один раз подтвердите доверие. |
| Выберите поля настроек | Согласуйте дополнительные обычные поля на обоих ноутбуках. |
| Конфликт изменений | Раскройте поле, сравните значения с номерами устройств и выберите нужное. Затем синхронизируйте ноутбуки. Конфликтные заметки для настроек не создаются. |
| Не применено | Прочитайте ошибку под строкой. При недоступной сети повторите после восстановления подключения. При несовместимой версии обновите Obsidian перед повтором. |
| Прерванная установка | Нажмите **Восстановить установку** для проверки резервных файлов и восстановления предыдущей установки. |

При сбое между заменами файлов TotalSync пытается вернуть предыдущие файлы и включение. Если откат не завершился, журнал остаётся для следующего восстановления. Остановка завершает текущую локальную транзакцию до безопасной точки. Вручную переименовывать lock, revisions или папки профилей для этого режима не требуется.

## Ограничения

- Режим применяется только на Windows. На iPhone продолжается синхронизация заметок и вложений.
- Пакет включает main.js, manifest.json, необязательный styles.css и дополнительный pdfannots2json.exe у Zotero Integration. Другие нестандартные файлы и внешние программы автоматически не переносятся.
- TotalSync не обновляет собственный код через этот механизм.
- История профилей в облаке и резервные установки в локальной папке TotalSync пока сохраняются без автоматической очистки. Локальные копии могут содержать пароли — не публикуйте их.
- Откат при ошибке и восстановление прерванной установки реализованы. Выбора произвольной старой версии плагина в общем окне **История** пока нет.
- Проверки с искусственными данными и HTTP WebDAV выполнены. Реальные сторонние плагины требуют описанной выше проверки на устройствах. Ручной тест отключения сети и стационарный ПК остаются отложенными.

## BRAT, GitHub и каталог Obsidian

GitHub уже хранит релизы TotalSync. BRAT устанавливает их из GitHub, включая prerelease. Для обновления тестового TotalSync не требуется предварительное включение в Community Directory.

7 ноября 2026 TotalSync 0.2.0 опубликован в Community Directory, проверка завершилась и установка активна. Стабильный выпуск можно устанавливать и обновлять через **Настройки → Сторонние плагины** самого Obsidian. Источником файлов остаются GitHub Releases. BRAT сохраняется как дополнительный канал тестовых версий; удалять существующий TotalSync для перехода к обновлениям каталога не требуется.
