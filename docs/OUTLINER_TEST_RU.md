# Проверка настроек Outliner — TotalSync 0.1.18

Проверяем свежую правку настройки между двумя существующими BTV_Base. Одинаковые исходные установки не мешают проверке. Outliner удалять не требуется. Новый ноутбук — первоначальный источник профиля; после подключения настройки передаются в обе стороны.

## Подготовка

1. Обновите TotalSync через BRAT до **0.1.18 на обоих ноутбуках**. В 0.1.17 перенос настроек Outliner 4.10.2 не работал из-за устаревших имён полей.
2. На старом ноутбуке откройте **Настройки → TotalSync → Плагины и настройки**. Если профиль ещё не принят, нажмите **Обновить источники → Получить этот профиль** у нового ноутбука. Новый ноутбук уже опубликован источником; повторная первичная настройка не нужна.
3. При запросе доверия скопируйте отпечаток из этого окна на новом ноутбуке, вставьте его на старом и нажмите **Сверить и доверять источнику**. Если есть ожидающие изменения, завершите работу в затронутых плагинах и выполните **Применить ожидающие изменения → Применить**.
4. У Outliner должен быть включён переключатель **Синхронизировать этот плагин на ноутбуке** на обоих устройствах. Для первой проверки выполняйте действия последовательно, меняя настройку только на одном ноутбуке за раз.

## Новый ноутбук → старый

1. Откройте **Настройки → Outliner** на обоих ноутбуках и запишите исходное положение **Draw vertical indentation lines** (вертикальные линии отступов).
2. На новом ноутбуке измените этот переключатель на противоположное значение. После перехода в другой раздел Outliner сохраняет настройку.
3. На новом ноутбуке нажмите **TotalSync → Плагины и настройки → Синхронизировать плагины** и дождитесь окончания.
4. На старом ноутбуке нажмите **Синхронизировать плагины**. Для активного Outliner может появиться **Ожидает применения**: выполните **Применить ожидающие изменения → Применить**. Затронутый плагин перезагрузится.
5. Заново откройте **Настройки → Outliner** на старом ноутбуке. Переключатель должен повторять новое значение источника.

## Старый ноутбук → новый

1. На старом ноутбуке верните переключатель в первоначальное положение.
2. Синхронизируйте плагины сначала на старом, затем на новом ноутбуке. Примените ожидающие изменения, если они появятся.
3. Заново откройте Outliner на новом ноутбуке. Переключатель должен вернуться в исходное положение.
4. Повторите синхронизацию без правок. Значение должно оставаться одинаковым, а Outliner — показывать **Применено** без конфликта.

Результат проверяйте по самому переключателю. Для дополнительной визуальной проверки откройте заметку с вложенным списком в режиме редактирования: при включении линии отступов видны, при выключении исчезают. Вид линий также зависит от темы Obsidian.

Если изменение не пришло, запишите версии TotalSync на обоих ноутбуках, статус строки Outliner и положение переключателя на каждом. Статус **Применено** в старой версии сам по себе не доказывает перенос нужного поля.
