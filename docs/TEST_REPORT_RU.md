## Замер времени

Один прогон на версию. Локальный WebDAV с искусственной задержкой 30 мс на запрос, два клиента, режим публикации через MKCOL. Время включает весь проход синхронизации. Пробы на реальном WebDAV Mail и отдельный замер файлового кеша в Obsidian сюда не входят.

| Сценарий | 0.1.5 | 0.1.6 |
| --- | ---: | ---: |
| Проверка без изменений | 192 мс / 6 запросов | 67 мс / 7 запросов |
| Отправка 15 небольших заметок | 1497 мс / 46 запросов | 651 мс / 46 запросов |
| Получение 15 небольших заметок | 673 мс / 21 запрос | 238 мс / 22 запроса |

При аудите TotalSync учтены использование результатов предыдущего прохода и параллельная очередь независимых операций в Remotely Save. [Алгоритм Remotely Save](https://github.com/remotely-save/remotely-save/blob/master/docs/sync_algorithm/v3/design.md) · [Код Remotely Save 0.5.25](https://github.com/remotely-save/remotely-save/blob/0.5.25/src/main.ts)
