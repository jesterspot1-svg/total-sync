# Отчёт о проверках 0.1.2

## Автоматический стенд

Локальный HTTP-сервер слушает loopback и моделирует WebDAV. Три клиента используют синтетические vault. HTTP-транспорт теста не отправляет запросы на Mail. Набор включает 33 теста и отдельный запуск собранного плагина на имитации Obsidian API.

## Ручные проверки

| Сценарий | Результат |
| --- | --- |
| Установка и первичный обмен в 0.1.0 | Пользователь подтвердил, что заметка со старого ноутбука появилась на новом ноутбуке и iPhone. После правки на iPhone Windows зарегистрировала повторяющийся `busy`. |
| Повтор в 0.1.1 | Пользователь подтвердил загрузку опубликованной правки на всех устройствах. Следующая отправка с iPhone ждала облачную блокировку. |
| Базовая проверка Mail с iPhone через VPN | Пользователь получил `probe-move` в 0.1.1. Проба чтения, записи и обычного MOVE прошла. |
| MOVE каталога с запретом перезаписи на Mail в 0.1.2 | Ожидает ручной проверки |
| Работа на iPhone, запуск после сворачивания и применение настроек Windows | Не запускалась на устройствах |
| Реальная проверка WebDAV Mail, ограничения, задержки, максимальные размеры | Не запускалась с учётной записью Mail |
| Рабочий vault и Remotely Save | Только локальный аудит структуры и манифестов. Реальные данные в тестах отсутствуют. |
