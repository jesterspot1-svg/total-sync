# Отчёт о проверках 0.1.0

## Автоматический стенд

Локальный HTTP-сервер слушает loopback и моделирует WebDAV. Три клиента используют синтетические vault. HTTP-транспорт теста не отправляет запросы на Mail. Набор включает 22 теста и отдельный запуск собранного плагина на имитации Obsidian API.

| Проверки | Результат |
| --- | --- |
| Первичная загрузка, двусторонний контент между тремя клиентами, отдельные vault ID | PASS |
| UTF-8, кириллица, переносимые пути и совпадения регистра | PASS |
| Вложения PNG, PDF, аудио и большой двоичный файл. Продолжение очереди после лимита | PASS |
| Перемещение заметок и вложений с сохранением папок и байтов | PASS |
| Офлайн-правка и повтор после восстановления сети | PASS |
| Два параллельных клиента и повтор одного запуска | PASS |
| Независимые правки Markdown. Обе версии и одна конфликтная копия | PASS |
| Конфликт JSON, сохранение активной конфигурации, извлечение обеих версий | PASS |
| Tombstone, восстановление, очистка спустя 30 дней и сохранение активных объектов | PASS |
| Массовое удаление, устаревшее подтверждение и неполная локальная сверка | PASS |
| HTTP 401, 403, 404, 429, 500, тайм-аут, пустой и оборванный XML | PASS |
| Прерванная фиксация облачной записи и повтор после ошибки локального применения темы | PASS |
| Отдельный канал Windows и изоляция mobile. Обмен снимком Bookmarks | PASS |
| Исключение секретных ключей из проверяемой конфигурации и исключение исполняемого кода | PASS |
| TypeScript, ESLint, сборка esbuild, проверка внешних импортов и шаблонов секретов | PASS |
| Загрузка готового пакета с имитацией Obsidian API, RU и английский fallback, маскированный пароль и скрытые настройки Windows на mobile | PASS |

## Ручные проверки

| Сценарий | Результат |
| --- | --- |
| Установка через BRAT в актуальном Obsidian на Windows | Не запускалась на реальном приложении |
