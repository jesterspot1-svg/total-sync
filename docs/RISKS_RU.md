# Риски и ограничения beta

| Риск | Что делает TotalSync |
| --- | --- |
| Ложное удаление из-за сбоя WebDAV | Удаление требует явной метки в опубликованной ревизии. Пустой или повреждённый PROPFIND останавливает операцию. Уже принятый индекс проверяется по SHA-256. |
| Массовое удаление | Останавливается от 25 удалений в канале или от двух, если их доля больше 10%. Подтверждение связано с ревизией и списком удалений. Файл, изменившийся во время операции, пропускается. |
| Разрыв соединения в момент записи | При проверенном MOVE с запретом перезаписи клиент может подтвердить готовую ревизию после сбоя. В прежнем режиме блокировка может остаться в облаке. Загрузка опубликованных файлов продолжается. Порядок проверки описан в [инструкции для beta](BETA_TEST_INSTRUCTION_RU.md). |
| Облако доступно третьей стороне | HTTPS защищает передачу. Mail видит содержимое, имена и историю. SecretStorage хранит пароль приложения локально. Избегайте секретов в именах синхронизируемых файлов. |
| Плагин или тема меняют параметры одновременно | Изменившийся файл пропускается. JSON-конфликты сохраняются в истории. Применённые настройки могут потребовать заново открыть хранилище. Диск хранит локальные резервные байты до ручной уборки тестового vault. |
| Сторонний исполняемый код | Синхронизируются инвентарь и ограниченные настройки Calendar. Community-плагины устанавливаются и включаются вручную. CSS с импортами, ссылками на ресурсы или экранированными конструкциями пропускается. |
| Закладки | Публичный Obsidian API не предоставляет безопасную операцию записи и перечитывания Bookmarks. Снимок можно опубликовать, получить и выгрузить в JSON. Живой файл остаётся под управлением Obsidian. |
| Ограничения платформы | iPhone синхронизируется при активном Obsidian. На iOS размер файла зависит от доступной памяти и WebDAV. TotalSync передаёт крупные файлы целиком, по одному. Лимит TotalSync составляет 32 МиБ на Android и 128 МиБ на компьютере. |
| Пути | Скрытые файлы и служебный каталог Obsidian исключены из контента. Не используйте симлинки, переименования только регистра и пути, непереносимые на Windows. Схему папок и обычные перемещения проверяет стенд. |
| Объём и задержки | Неизменившиеся файлы используют свежий хеш из памяти. Первый проход, пересканирование и проверка цепочки индексов при привязке большого vault могут занять время. Индексы и tombstones сохраняются для обнаружения отката, включая после очистки старых бинарных объектов. |
| Хранение истории | Очистка выполняется после 30 суток, когда сервер присылает время и оно совпадает с локальным с допуском пять минут. Неиспользованные объекты прерванной публикации могут занимать место до удаления изолированного тестового vault. |
| Существующий Remotely Save | Формат облака и шифрование Remotely Save требуют отдельной проверки. В beta используются независимые папки и искусственные заметки. |

Официальные материалы [Obsidian Developer Policies](https://docs.obsidian.md/community-directory/developer-policies), [мобильная разработка Obsidian](https://docs.obsidian.md/Plugins/Getting%20started/Mobile%20development), [WebDAV Облака Mail](https://help.mail.ru/cloud/desktop/webdav/).
