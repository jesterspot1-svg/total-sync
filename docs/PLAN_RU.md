# Этапы TotalSync

| Этап | Критерий приёмки |
| --- | --- |
| 1. Аудит | Проверены исходный vault, каталог и правила Obsidian. Определены границы beta и порядок резервного копирования. |
| 2. Каркас | Строгий TypeScript, esbuild, RU/EN, нативные настройки, проверка HTTPS WebDAV и безопасное хранение пароля. |
| 3. Контент | Три искусственных клиента обмениваются заметками и вложениями. Разрыв сети, конфликт и неполный ответ сервера сохраняют данные. |
| 4. Настройки | Каналы разделены. Windows передаёт разрешённые настройки и инвентарь. iOS получает контент и при включении снимки закладок. |
| 5. Надёжность | Проверены удаление и восстановление, ограничение массовых удалений, повторное выполнение и сборка без Node.js в плагине. |
| 6. Beta | Публичный репозиторий, зелёный CI, GitHub prerelease `0.1.0` и инструкция ручного тестирования. |
| 7. Приёмка beta | Пользователь подтвердил обмен заметками, разбор конфликтов, мобильные кнопки и последующие проверки. Ручное отключение сети и стационарный ПК отложены по его просьбе. Это остаётся ограничением проверки. |
| 8. Перенос рабочего хранилища | BTV_Base перенесён и подключён на двух ноутбуках и iPhone. Пользователь подтвердил работу. Новый ноутбук выбран первоначальным источником плагинов. Настройка Outliner проверена в обе стороны, включая фактическое состояние на новом ноутбуке. Не все параметры всех плагинов проверены вручную. |
| 9. Community Plugins | 7 ноября 2026 опубликован стабильный релиз 0.2.0 после аудита, оптимизации и проверки блокировок и автоматических повторов. CI Windows/Linux и сборка релиза прошли; версия установлена на новом ноутбуке. Пользователь принял условия разработчика, заявка отправлена, [карточка TotalSync опубликована](https://community.obsidian.md/plugins/total-sync). Проверка каталога Completed / Satisfactory, сборка воспроизведена побайтово, кнопка Add to Obsidian активна. Неблокирующие рекомендации записаны в отчёте аудита. |

| 10. Настройки и WebDAV 0.3.0 | Добавлены выбор языка, совместимые HTTPS WebDAV, смена подключения, индикатор в строке состояния и переход к штатным обновлениям. Упрощены инструкции RU/EN. Релиз опубликован и установлен на новом ноутбуке; 117 тестов и CI Windows/Linux прошли, рабочая синхронизация: 905 проверенных файлов, 0 блокировок. Сохранение отдельного About в Community проверяется отдельно. |

Актуальные доказательства и оставшиеся ограничения: [аудит 0.2.0](COMMUNITY_RELEASE_AUDIT_RU.md), [проверка и публикация 0.3.0](RELEASE_0.3.0_RU.md). Пункты, отложенные пользователем, не отмечаются как выполненные.
