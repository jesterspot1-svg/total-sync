# Этапы TotalSync

| Этап | Критерий приёмки |
| --- | --- |
| 1. Аудит | Проверены исходный vault, каталог и правила Obsidian. Определены границы beta и порядок резервного копирования. |
| 2. Каркас | Строгий TypeScript, esbuild, RU/EN, нативные настройки, проверка HTTPS WebDAV и безопасное хранение пароля. |
| 3. Контент | Три искусственных клиента обмениваются заметками и вложениями. Разрыв сети, конфликт и неполный ответ сервера сохраняют данные. |
| 4. Настройки | Каналы разделены. Windows передаёт разрешённые настройки и инвентарь. iOS получает контент и при включении снимки закладок. |
| 5. Надёжность | Проверены удаление и восстановление, ограничение массовых удалений, повторное выполнение и сборка без Node.js в плагине. |
| 6. Beta | Публичный репозиторий, зелёный CI, GitHub prerelease `0.1.0` и инструкция ручного тестирования. |

После beta ожидаем результаты Windows и iPhone. Затем возможны исправления и новые prerelease. Порядок переноса реальных данных после отдельного разрешения — старый ноутбук → новый ноутбук → стационарный ПК → iPhone. Подача в Community требует отдельного согласия.
