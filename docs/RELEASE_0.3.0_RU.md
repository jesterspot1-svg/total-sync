# TotalSync 0.3.0: изменения и проверка

## Что изменилось

- Язык выбирается в настройках самого TotalSync: русский, английский или язык Obsidian. Выбор действует локально и меняет команды без перезапуска.
- Вместо одного адреса Mail доступен произвольный адрес WebDAV по HTTPS с логином и паролем, включая отдельный порт и вложенную папку. Перед привязкой проверяются необходимые операции сервера. OAuth-only, HTTP и недоверенные сертификаты не поддерживаются.
- Сохранённый пароль привязан к нормализованному адресу и локальному подключению. Старый вход Mail копируется в новый секрет без удаления общего секрета, который ещё может использовать другое хранилище.
- Кнопка «Сменить сервер или аккаунт» отключает прежнюю привязку, освобождает поля и создаёт новую локальную идентичность. Заметки и файлы прежнего облака сохраняются; старая точка синхронизации и доверие профилям не применяются к новому облаку.
- На компьютере индикатор, счётчик, остановка и результат переехали в строку состояния. Успешный автоматический проход без правок тоже показывает галочку. После ошибки остаётся значок ошибки рядом со временем последнего успешного прохода.
- Кнопка обновления открывает родную карточку TotalSync через URI Obsidian. Плагин не скачивает и не устанавливает собственный код.
- README RU/EN упрощены: таблица возможностей, четыре шага начала работы, основные кнопки и ссылки на подробности. Подготовлен текст короткого описания и About для каталога.

## Автоматические проверки

Локально прошли TypeScript, ESLint без ошибок, 117 тестов, сборка, smoke-проверка собранного плагина и проверка состава релиза. ESLint сохраняет рекомендации по декларативным определениям настроек и общим таймерам WebDAV, используемым также в Node-фикстуре.

Новые сценарии: нормализация HTTPS-адресов, отказ от пароля внутри URL, порт и Unicode-путь, обмен между двумя устройствами во вложенной папке со старым и эксклюзивным протоколом MOVE; переключение RU/EN и команд, миграция секрета, запрет передачи пароля при смене адреса, запрет смены привязки во время синхронизации, отдельная идентичность после отключения, галочка автоматического прохода и очистка ресурсов.

## Проверка установленной версии

На новом ноутбуке создана локальная резервная копия прежних файлов плагина и его состояния, затем установлена 0.3.0. Существующее подключение и 16 профилей плагинов сохранены. Проверка на рабочем хранилище завершилась с `checked=905`, `blocked=0`, без ошибок; индикатор показал успех. Переключение на английский изменило настройки и команды; после проверки возвращён язык Obsidian. Кнопка обновления открыла родную карточку TotalSync, где установлена версия 0.3.0. Облачная привязка для этой проверки не сбрасывалась.

## Проверка пользователем

1. На новом ноутбуке откройте «Настройки → TotalSync» и проверьте версию 0.3.0.
2. В «Language / Язык» выберите English, затем Русский. Текст настроек и команды должны измениться. Верните удобный язык.
3. Запустите синхронизацию. На компьютере не должно быть плавающей плашки: в строке состояния вращается иконка, во время передачи есть счётчик и остановка, после успеха — галочка.
4. Дождитесь следующего периодического прохода без новых правок. Галочка должна появиться и после него. Аналогично проверьте при следующем обычном открытии Obsidian.
5. Нажмите «Проверить и обновить». Должна открыться карточка TotalSync внутри Obsidian. Если установлена актуальная версия, кнопка нового обновления не требуется.
6. Для проверки другого WebDAV используйте отдельное тестовое локальное хранилище и отдельную пустую папку на сервере. Укажите адрес HTTPS, логин и пароль, проверьте подключение, создайте ID, отправьте тестовую заметку и подключите второе тестовое устройство по тому же адресу и ID.
7. В тестовом хранилище нажмите «Сменить сервер или аккаунт». После подтверждения синхронизация должна быть выключена, поля доступны, тестовая заметка на месте, а пароль для нового адреса нужно ввести заново.

Рабочее BTV_Base для проверки смены сервера переподключать не требуется. Подключение Mail и Windows-профили при обычном обновлении сохраняются. Реальная совместимость всех провайдеров не проверена; общий протокол проверен стендом, Mail — на рабочем хранилище. На iPhone сохраняется компактная плашка. Отложенные пользователем физическое отключение сети и стационарный ПК не объявляются проверенными.
