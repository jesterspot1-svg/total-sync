# План тестирования

## Устройства

| Устройство | Роль |
| --- | --- |
| Старый ноутбук Windows | Создаёт тестовый ID и первичные искусственные заметки. |
| Новый ноутбук Windows 11 | Получает первичные файлы в `TotalSync-Beta`. После отдельного разрешения одноимённый рабочий vault примет полную резервную копию. |
| Стационарный ПК Windows | Второй получатель настроек и участник теста конфликтов. |
| iPhone | Обмен контентом и снимком закладок. Проверка изоляции канала Windows. |

## Что сверить

| Сценарий | Критерий |
| --- | --- |
| Подключение | Синтетическая запись, чтение, удаление и исключительное создание каталога проходят на Mail. |
| Заметки и вложения | Кириллица, пробелы, вложенные каталоги, небольшой PDF, изображение и аудиофайл читаются на всех устройствах. |
| План | План показывает входящие и исходящие операции. Предпросмотр сохраняет текущее состояние файлов. |
| Изменения офлайн | Локальная правка остаётся доступной. После восстановления сети её получает второе устройство. |
| Конфликты | Совместимые правки Markdown объединяются в исходной заметке. Пересекающиеся правки можно разобрать в окне TotalSync, а обе исходные версии Markdown или JSON можно экспортировать из истории. |
| Настройки Windows | Сниппет и безопасные горячие клавиши загружаются после перезапуска vault. Инвентарь сверяется через палитру команд. |
| Удаление и восстановление | Одиночное удаление распространяется и восстанавливается из истории. Массовое удаление ждёт подтверждения. |
| Телефон | Контент виден в обе стороны при открытом Obsidian. Настройки Windows отсутствуют. Снимок закладок можно экспортировать. |
| Откат | После остановки beta рабочий Obsidian продолжает использовать прежнюю связку. Очистка затрагивает только тестовый ID. |
