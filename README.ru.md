# TotalSync

[English](README.md) · [Инструкция для beta](docs/BETA_TEST_INSTRUCTION_RU.md)

TotalSync — бесплатный плагин Obsidian для синхронизации через [WebDAV Облака Mail](https://help.mail.ru/cloud/desktop/webdav/). Заметки и вложения, настройки Windows и снимки закладок передаются по отдельным каналам в пределах одного удалённого ID.

**Версия 0.1.16 — тестовый релиз.** Новый профиль плагинов сначала проверьте на искусственных данных по [отдельной инструкции](docs/COMMUNITY_PLUGINS_RU.md). Требуется Obsidian 1.11.5 или новее. Файлы идут по HTTPS, а в облаке доступны провайдеру, включая имена и историю. Шифрования содержимого на стороне плагина в этой версии нет. Пароль приложения сохраняется локально в SecretStorage Obsidian.

- На Windows и iPhone синхронизируются папки, заметки и вложения. На iOS TotalSync передаёт файлы без собственного ограничения размера. На компьютере лимит одного файла составляет 128 МиБ, на Android — 32 МиБ.
- Плашка показывает число обработанных файлов, итог синхронизации и кнопку остановки текущего прохода. Строка состояния на компьютере и настройки TotalSync показывают, сколько прошло с последней успешной синхронизации. Ручной запуск доступен в левой панели на компьютере и в нижнем меню Obsidian на телефоне.
- Между Windows передаются разрешённые настройки vault, горячие клавиши, безопасные CSS-сниппеты и темы. В **Плагины и настройки** можно настроить перенос пакетов плагинов, точных версий, включения и переносимых параметров. Плагины из каталога устанавливаются без PowerShell; для остальных один раз сверяется отпечаток ключа ноутбука-источника. Сам TotalSync этим механизмом не обновляется.
- Подготовлены перечни обычных настроек для 16 плагинов, включая рабочую версию Excalidraw 2.25.3. Дополнительные поля можно выбрать на обоих ноутбуках. Авторизация, машинные пути и разрешения запуска остаются локальными. Поддерживаемое горячее применение не закрывает плагин; в остальных случаях используется **Применить ожидающие изменения**. [Пошаговая проверка](docs/COMMUNITY_PLUGINS_RU.md)
- Закладки можно отправить и получить как снимок. Скопированные и восстановленные версии появляются в `TotalSync-Recovery`, которая исключена из синхронизации.
- Независимые правки Markdown могут объединиться в исходной заметке. Пересекающиеся правки разбираются в окне TotalSync. Обе исходные версии сохраняются в истории. Для спорного JSON действующий файл остаётся на месте, а версии доступны через историю.

Новый режим выключен по умолчанию. В Mail передаются подписанные профили и файлы плагинов; подпись подтверждает источник, но не шифрует данные. Закрытый ключ остаётся в SecretStorage. Для поиска официальных пакетов используются `raw.githubusercontent.com`, `github.com` и перенаправления на файлы релизов, без учётных данных Mail. Доверие ноутбуку распространяется на его будущие подписанные пакеты.

История профилей и локальные копии установок пока не очищаются автоматически. Локальные копии могут содержать авторизацию — не публикуйте их. Пакет включает `main.js`, `manifest.json`, необязательный `styles.css` и помощник Zotero `pdfannots2json.exe`. Другие вспомогательные файлы требуют отдельной настройки. На iPhone этот режим не применяется.
