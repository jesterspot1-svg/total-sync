# TotalSync

[English](README.md) · [Установить TotalSync](https://community.obsidian.md/plugins/total-sync) · [Подробная инструкция](docs/USER_GUIDE_RU.md)

**Одни и те же заметки и файлы Obsidian на ноутбуке и телефоне — через ваше хранилище WebDAV.** Измените заметку, синхронизируйте устройства и продолжайте работу. Плагин бесплатный.

## Что переносится

| Данные | Компьютеры и телефоны | Между компьютерами Windows |
| --- | --- | --- |
| Заметки, папки и вложения | Да | Да |
| Выбранные настройки Obsidian | — | Да |
| Плагины и их переносимые настройки | — | По желанию |
| Закладки | Снимками, по желанию | Снимками, по желанию |

Независимые правки Markdown могут объединяться автоматически. Если изменено одно и то же место, TotalSync предложит выбрать текст и сохранит исходные версии для восстановления.

## Начать за четыре шага

Понадобятся **Obsidian 1.11.5+**, **адрес WebDAV по HTTPS, логин и пароль**. Некоторые провайдеры требуют отдельный пароль приложения. Поддерживаются Облако Mail и другие совместимые серверы WebDAV. Условия хранения и тарифы определяет ваш провайдер.

1. **Установите плагин.** Настройки → Сторонние плагины → Обзор → TotalSync → Установить → Включить. Сохраните резервную копию заметок и выключите другие средства синхронизации этого хранилища.
2. **Подключите первое устройство.** В настройках TotalSync укажите адрес WebDAV и данные входа. Нажмите **Проверить подключение**, затем **Создать ID → Создать в облаке**.
3. **Отправьте данные.** Откройте **Показать план операций**, включите синхронизацию и нажмите **Синхронизировать сейчас**. Дождитесь окончания первой отправки.
4. **Добавьте другое устройство.** Установите TotalSync в его локальное хранилище, введите те же адрес и данные входа, вставьте ID первого устройства и нажмите **Подключить по ID**. Проверьте план и включите синхронизацию. Пароль вводится на каждом устройстве отдельно.

Для переноса плагинов Windows откройте **Плагины и настройки**: опубликуйте профиль на компьютере с нужными настройками и получите его на другом. [Пошаговая инструкция](docs/COMMUNITY_PLUGINS_RU.md).

## Удобные настройки

- **Язык:** «Как в Obsidian», «Русский» или «English» прямо в TotalSync.
- **Строка состояния на компьютере:** вращающаяся иконка, число файлов и остановка во время работы; галочка и время последней синхронизации после успеха. Галочка появляется и после автоматического запуска.
- **Автоматический запуск:** при открытии, после правок или через выбранный интервал. После временных ошибок плагин повторяет попытку.
- **Другой WebDAV:** кнопка **Сменить сервер или аккаунт** отключает старую привязку и открывает поля для нового подключения. Заметки и файлы в старом облаке сохраняются.
- **Обновления:** кнопка **Проверить и обновить** открывает карточку TotalSync внутри Obsidian. Проверку и установку выполняет Obsidian; BRAT нужен только по желанию для тестовых версий.

На iPhone держите Obsidian открытым до завершения синхронизации. Компактная плашка с прогрессом и быстрая команда сохраняются, поскольку настольной строки состояния на телефоне нет.

## Где хранятся данные

Файлы отправляются прямо на выбранный сервер WebDAV по HTTPS. **Шифрования содержимого на стороне плагина и телеметрии нет.** Провайдер может читать загруженные данные. Пароли остаются в локальном SecretStorage Obsidian.

Перенос плагинов Windows включается отдельно. Пакеты вне каталога требуют подтверждения источника; официальные пакеты загружаются из GitHub. Пароли, пути конкретного компьютера и разрешения запуска остаются локальными. Для части работающих плагинов нужно нажать **Применить ожидающие изменения**. [Данные и ограничения](docs/DATA_AND_PRIVACY.md).

**Уже пользуетесь TotalSync?** Обновите плагин на устройствах и оставьте прежние ID и настройки. Подключение Mail переносится автоматически. Переподключать хранилище ради обновления до 0.3.0 не нужно. [Восстановление и ошибки](docs/USER_GUIDE_RU.md#ошибки-сети-и-блокировки).
