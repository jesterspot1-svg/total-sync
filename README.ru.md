# TotalSync

[English](README.md) · [Инструкция для beta](docs/BETA_TEST_INSTRUCTION_RU.md)

TotalSync — бесплатный плагин Obsidian для синхронизации через [WebDAV Облака Mail](https://help.mail.ru/cloud/desktop/webdav/). Заметки и вложения, настройки Windows и снимки закладок передаются по отдельным каналам в пределах одного удалённого ID.

**Версия 0.1.1 предназначена для тестовых хранилищ с искусственными данными.** Требуется Obsidian 1.11.5 или новее. Файлы идут по HTTPS, а в облаке доступны провайдеру, включая имена и историю. Шифрования содержимого на стороне плагина в этой версии нет. Пароль приложения сохраняется локально в SecretStorage Obsidian.

- На Windows и iPhone синхронизируются папки, заметки и вложения. Лимит одного файла — 128 МиБ на компьютере и 32 МиБ на телефоне.
- Между Windows передаются разрешённые настройки vault, горячие клавиши, безопасные CSS-сниппеты и темы, инвентарь плагинов и отдельно включаемые параметры Calendar. Установка и обновление плагинов выполняются через менеджер Obsidian.
- Закладки можно отправить и получить как снимок. Скопированные и восстановленные версии появляются в `TotalSync-Recovery`, которая исключена из синхронизации.
- При одновременной правке Markdown сохраняются обе версии. Для спорного JSON действующий файл остаётся на месте, а версии доступны через историю.
