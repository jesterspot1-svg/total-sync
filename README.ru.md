# TotalSync

[English](README.md) · [Инструкция для beta](docs/BETA_TEST_INSTRUCTION_RU.md)

TotalSync — бесплатный плагин Obsidian для синхронизации через [WebDAV Облака Mail](https://help.mail.ru/cloud/desktop/webdav/). Заметки и вложения, настройки Windows и снимки закладок передаются по отдельным каналам в пределах одного удалённого ID.

**Версия 0.1.14 предназначена для тестовых хранилищ с искусственными данными.** Требуется Obsidian 1.11.5 или новее. Файлы идут по HTTPS, а в облаке доступны провайдеру, включая имена и историю. Шифрования содержимого на стороне плагина в этой версии нет. Пароль приложения сохраняется локально в SecretStorage Obsidian.

- На Windows и iPhone синхронизируются папки, заметки и вложения. На iOS TotalSync передаёт файлы без собственного ограничения размера. На компьютере лимит одного файла составляет 128 МиБ, на Android — 32 МиБ.
- Плашка показывает число обработанных файлов, итог синхронизации и кнопку остановки текущего прохода. Строка состояния на компьютере и настройки TotalSync показывают, сколько прошло с последней успешной синхронизации. На компьютере можно включить кнопку ручного запуска в левой панели.
- Между Windows передаются разрешённые настройки vault, горячие клавиши, безопасные CSS-сниппеты и темы, инвентарь и отдельно включаемые параметры Calendar и Excalidraw. Недостающие плагины из каталога можно установить по одному или пакетом через Obsidian CLI. Перед включением Excalidraw обновите TotalSync на всех устройствах. [Перенос плагинов и настроек](docs/COMMUNITY_PLUGINS_RU.md)
- Закладки можно отправить и получить как снимок. Скопированные и восстановленные версии появляются в `TotalSync-Recovery`, которая исключена из синхронизации.
- Независимые правки Markdown могут объединиться в исходной заметке. Пересекающиеся правки разбираются в окне TotalSync. Обе исходные версии сохраняются в истории. Для спорного JSON действующий файл остаётся на месте, а версии доступны через историю.
